# Contributing

Run `node web/tests/model.test.mjs` and `python -m unittest discover -s tests -v`, plus the README workflow. Preserve seeded behavior, units, model limits and web/Python parity. New models require equations, domains, reference checks and explicit uncertainty/validation limits.

Keep measured inputs separate from synthetic outputs. Do not interpret zero sampled errors as zero probability or a raw correlation maximum as a validated detection. Do not turn hashes or software tests into authenticity, novelty or scientific approval claims. Protect credentials and unpublished partner data. Submit focused pull requests with behavior and verification evidence.
